# BUGWORKS ステージ1（1-1〜1-5）・実装準備資料 v0.1

## ファイルの位置づけ
- `stage_1_*.png` は**画面イメージを切り出した参考画像**。3Dモデル・透過スプライトではない。
- `stage1_blockout.json` は**実装開始用の仮座標**。ゲームエンジンで衝突判定・勾配・射出速度・接続位置の検証が必要。
- 初期物理更新は120Hz。演算結果が端末間で完全一致する保証はなく、将来の設計図互換性と検証再現性の設計が必要。
- UI画像の文字はデザイン参考であり、実装時はゲーム内フォントによるテキスト描画を推奨。

## 最初の5分（目安）
| 時間 | 体験 | 操作 |
|---|---|---|
| 0:00–0:45 | S-404登場・視点操作 | ドラッグで回転、ピンチ/ホイールでズーム |
| 0:45–1:45 | 1-1 直線レール配置 | 選択、スナップ配置、再生 |
| 1:45–2:45 | 1-2 バネでジャンプ | 高さ調整、試行錯誤 |
| 2:45–3:35 | 1-3 曲線で方向転換 | 部品回転、接続 |
| 3:35–4:25 | 1-4 歯車と橋 | 動力の伝達、再生 |
| 4:25–5:00 | 1-5 設計図保存 | 名前入力、ローカル保存 |

時間は初回の目安。失敗しても制限時間で打ち切らない。

## クリアと隠しバグ
- 1-1〜1-4は必要なイベントが発生したときにクリア。1-5はローカル保存まで完了してクリア。
- 隠しバグは通常クリアの必須条件にしない。S-404の台詞で『変なことが起きる可能性』だけ示す。
- ステージをクリアしても自由研究モードで再挑戦可能。

## 保存方式
- 初期版はローカルJSONをダウンロード/インポート。サーバー、アカウント、公開ギャラリーは不要。
- 保存データに schemaVersion, stageId, parts, connections, creatorDefinedName を含める。
- インポート時は形式検証・部品ID検証・サイズ/個数上限・接続先整合性を確認する。

## 画像素材
コンセプトシートから各ステージ、チュートリアル、操作ガイド、保存UIを切り出したPNGを同梱。切り出し画像は不透明背景を含む。
