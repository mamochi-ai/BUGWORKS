# Claude Code 実装開始用プロンプト（コピペ用）

BUGWORKSというWeb先行の3D物理工作パズルを実装します。まず `BUGWORKS_MASTER_SPEC.md` を読み、`reference/` 内のJSONも確認してください。仕様の未決事項は勝手に確定せず `DECISIONS.md` に候補と判断理由を書いてください。

**最初の作業範囲は縦切り試作のみ**です。TypeScript/Vite/Three.jsを第一候補として技術選定し、研究所の簡易床、自由カメラ、レール、鉄球、再生/停止/リセットを実装してください。iPadのタッチ操作を優先し、描画と固定120Hzの物理演算を分離してください。大容量の画像シートを3Dモデルと誤認しないでください。

次に、README（起動手順）、テスト方針、今後のTODO、仕様との不一致を出してください。40種のバグや永久機関認定を最初から全部作らず、検証可能な最小構成から進めてください。サーバー、SNS、オンラインランキング、クラウド共有を追加しないでください。
